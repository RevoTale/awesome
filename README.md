# awesome
A curated list of the repositories that are recommended to use based on the context of the technology.

## For Web Client App
- [react](https://github.com/facebook/react) - The library for web and native user interfaces.
  - [next.js](https://github.com/vercel/next.js) - The React Framework.
  - [use-debounce](https://github.com/xnimorz/use-debounce) - A basic debounce hook for react.
- [TypeScript](https://github.com/microsoft/TypeScript)
- [eslint](https://github.com/eslint/eslint) - Find and fix problems in your JavaScript code.
  - [eslint-config-love](https://github.com/mightyiam/eslint-config-love) - A TypeScript ESLint config that loves you
  - [eslint-config-nice-nextjs](https://github.com/RevoTale/eslint-config-nice-nextjs) - Strict ESLint config for Next.js applications.
  - [eslint-plugin-prettier](https://github.com/prettier/eslint-plugin-prettier) - ESLint plugin for Prettier formatting
### GraphQL Client
- [GraphQL Code Generator](https://github.com/dotansimha/graphql-code-generator) - A tool for generating code based on a GraphQL schema and GraphQL operations (query/mutation/subscription), with flexible support for custom plugins.
- [Apollo Client](https://github.com/apollographql/apollo-client) - GraphqQL Client that delivers powerful caching, intuitive APIs, and comprehensive developer tools to accelerate your app development.
### Styling
- [TailwindCSS](https://github.com/tailwindlabs/tailwindcss) - A utility-first CSS framework for rapid UI development.
### UI
- [shadcn/ui](https://github.com/shadcn-ui/ui) - A set of beautifully-designed, accessible components and a code distribution platform. Works with your favorite frameworks.
### Date Utilites
- [date-fns](https://github.com/date-fns/date-fns)
- [dayjs](https://www.npmjs.com/package/dayjs)
### Work with files
- [jszip](https://github.com/Stuk/jszip) - Create, read and edit .zip files with Javascript.
- [xlsx](https://github.com/SheetJS/sheetjs) - 📗 SheetJS Spreadsheet Data Toolkit
### Icons
- [lucide-react](https://github.com/lucide-icons/lucide) - Beautiful & consistent icon toolkit made by the community. Open-source project and a fork of Feather Icons.
